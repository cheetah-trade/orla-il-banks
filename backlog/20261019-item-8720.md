# Безопасная сводка последнего прогона: одна команда для отчёта

Для кого: человек без опыта терминала, у которого банк не сработал, и тот, кто делает живую проверку по docs/live-check.md. Сейчас README просит «прислать, что напечатал run»: человек копирует кусок терминала или скриншот, часть теряется, и он боится, что отправил лишнее. Отчёты живых прогонов — узкое место фазы 1 (на 19.10 ни одного). Что сделать: команда (например `orla-il-banks report`), которая по последнему логу из ~/.orla-il-banks/logs печатает короткую сводку и предлагает скопировать её: версия пакета и библиотеки, ОС, способ запуска (компьютер, GitHub, Docker), по каждому банку id, исход (ок / тип ошибки из таблицы «When something fails»), число строк отправлено / отказано и причины отказов. Путь: run упал → в уведомлении и в последней строке run написано «чтобы сообщить о проблеме, запустите report» → человек запускает → видит сводку → отправляет её. Состояния: логов нет («ещё не было ни одного запуска»), последний run успешный (сводка всё равно печатается), лог повреждён (понятная ошибка, код 2). Вне рамок: отправка сводки куда-либо самой программой.

## Acceptance criteria

- Тест: в сводке нет пароля, userCode, номера счёта или карты, токена Orla, даже если они есть в логе (проверено на логе с такими строками)
- Сводка печатается в трёх состояниях: нет логов, последний run успешный, последний run с ошибкой банка и с отказами Orla
- Последняя строка неудачного run и текст уведомления называют команду report
- README (раздел «When something fails» и «Reporting a problem») и docs/live-check.md просят присылать сводку report
- Работает на macOS и Windows в CI
