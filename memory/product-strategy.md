# Стратегия orla-il-banks (ЧЕРНОВИК Product lead, 15.10, владелец ещё не утвердил)

ЧЕРНОВИК, не решение владельца. Составлен по README и истории коммитов 15.10.
Куда идём: человек в Израиле, у которого счета и карты в израильских банках, получает свои операции в Orla без того, чтобы отдавать Orla пароль от банка. Пакет orla-il-banks (npm, версия 0.3.1) запускается у него на компьютере, в приватном репозитории GitHub или в Docker.
Цель (черновик): каждый поддерживаемый банк и карта проверены живым запуском, и человек проходит от setup до первых операций в Orla сам, без поддержки.
Мера (черновик): число банков и карт с подтверждённым живым запуском из 17 в README; доля людей, у кого после setup была хотя бы одна успешная доставка за 7 дней (если Orla это может посчитать).
Чего не делаем: не храним пароли от банков у Orla, не подключаем Behatsdaa (двойной счёт), не ставим israeli-bank-scrapers на latest.
Ограничения: только подписки, никаких платных API; живой запуск требует настоящих логинов в банк, их есть только у людей, у агентов нет; Hapoalim только с собственного компьютера после trust; One Zero только из терминала.
Как работаем: Kanban с маленькими релизами (0.x, RELEASING.md), фаза 1–2 недели с одной заметной клиенту целью. Scrum не нужен: команда маленькая.
Как проверено: прочитаны README.md, RELEASING.md и git log (16 коммитов, 0.1.0 → 0.3.1). В README написано «Status: early… not yet run live against every bank».
