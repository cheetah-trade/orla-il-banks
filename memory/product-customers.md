Слов клиентов пока не записано: на 26.10 нет ни отзывов, ни обращений, ни живых отчётов (таблица Results в docs/live-check.md пуста, GitHub issues нет).
Сегменты (по README): 1) люди со своим Mac или Windows, которые запускают setup в терминале (основной путь); 2) люди с GitHub, которые ставят ежедневный запуск в приватный репозиторий (без Hapoalim); 3) технические люди, которые запускают в Docker. Первые реальные пользователи по решению владельца 15.10 — он сам и 2–3 знакомых, проверяющих банки по docs/live-check.md.
Работа, ради которой берут (JTBD): «хочу видеть операции из израильского банка и карты в Orla и не отдавать никому пароль от банка».
Активация: ключ выпущен в Orla, setup прошёл, первый run доставил операции хотя бы одного банка. Главные риски: банк ни разу не проверен живым запуском; SMS-код Hapoalim (нужен trust); человеку непривычен терминал; страх прислать в отчёте пароль или номер счёта (его снимает команда report, пункт 20261019-item-8720).
Удержание: ежедневный запуск работает неделями (launchd или Task Scheduler), ключ не истёк, банк не потребовал сменить пароль; на Windows профиль Hapoalim с сессией банка закрыт ACL (PR #12, 0.3.2). Сбои показываются уведомлением.
Пробелы: число активировавшихся не меряем (пункт 20261019-item-68e5); удержание через 7 и 30 дней — следом за ним, кандидат в product-candidates.
