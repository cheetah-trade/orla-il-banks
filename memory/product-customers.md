# Клиенты orla-il-banks: сегменты и активация (черновик, слов клиентов пока нет)

Слов клиентов пока не записано: на 15.10 нет ни отзывов, ни обращений.
Сегменты (по README): 1) люди со своим Mac или Windows, которые запускают setup в терминале (основной путь); 2) люди с GitHub, которые ставят ежедневный запуск в приватный репозиторий (без Hapoalim); 3) технические люди, которые запускают в Docker.
Работа, ради которой берут (JTBD): «хочу видеть операции из израильского банка и карты в Orla и не отдавать никому пароль от банка».
Активация: ключ выпущен в Orla, setup прошёл, первый run доставил операции хотя бы одного банка. Главные риски: банк ни разу не проверен живым запуском; SMS-код Hapoalim (нужен trust); человеку непривычен терминал.
Удержание: ежедневный запуск работает неделями (launchd или Task Scheduler), ключ не истёк, банк не потребовал сменить пароль. Сбои показываются уведомлением.
Пробел, который надо закрыть: число активировавшихся мы не меряем. Нужно узнать, может ли Orla посчитать источники «Israeli banks» хотя бы с одной доставкой.
