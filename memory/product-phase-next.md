# Следующая фаза orla-il-banks: 2 «Свежая версия и отчёт в одну команду», 02.11–13.11 (предложение Product lead 19.10)

Goal

Measure
1) Банков и карт, подтверждённых живым запуском на выпущенной в фазе версии: не меньше 7 из 17. Читать: колонка Live-checked в README, метрика product «Live-checked banks and cards» (19.10: 0).
2) Впервые записано число активаций: ключи Israeli banks хотя бы с одной доставкой (метрика product «Activations: Israeli banks»; базовое значение, цели пока нет).

02.11–13.11 (две недели, сразу после фазы 1, которая идёт до 30.10).

Release criteria
1) Новая версия (0.4.0) выпущена по RELEASING.md с да владельца на тег: на ней актуальная israeli-bank-scrapers, README, шаблон GitHub Actions и RUNNER_VERSION в приложении Orla показывают её.
2) В версии есть report: сводка без паролей, логинов, номеров счетов и токена (тест), README и docs/live-check.md просят присылать её.
3) В колонке Live-checked у каждого подтверждённого банка версия; банки, которые задело обновление библиотеки, перепроверены или помечены «проверен на 0.3.x».
4) Записано, где Orla считает активации, и первое значение метрики; или в проекте Orla заведён пункт с точным запросом.

Resources
Разработка: два пункта фазы занимают оба автоматических места по очереди (сначала …-8235, затем …-8720), впереди эпика «Агентная обвязка», как в фазе 1; примерно 4–6 запусков, около 3–5% недели одной подписки.
