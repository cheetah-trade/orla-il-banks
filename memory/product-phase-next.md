# Предложение фазы 1 orla-il-banks: живые запуски по банкам (ждёт Approve владельца)

ПРЕДЛОЖЕНИЕ Product lead от 15.10, владелец ещё не утвердил.
Фаза 1, «Проверено живым запуском», 2 недели (16.10–30.10).
Цель, которую заметит клиент: в README у каждого банка и карты написано, проверен ли он живым запуском и когда; найденные сбои исправлены в 0.3.x.
Мера: банков и карт с подтверждённым живым run (сейчас неизвестно, вероятно 0–2 из 17). Цель — не меньше 7: Hapoalim, Leumi, Discount, Mizrahi, Isracard, Max, Visa Cal.
Критерии релиза: 1) в README есть колонка «Live-checked», в ней дата и версия; 2) по каждому сбою в живом запуске есть пункт разработки или исправление в релизе; 3) в README стоит pin на новую версию.
Зависимость: живые запуски делают только люди со своими логинами (владелец или те, кого он позовёт). Агенты этого не могут. Разработка готовит протокол прогона (run --dry-run, что прислать), потом разбирает присланные логи.
Пункты разработки на эту фазу ещё не заведены: их ставлю после Approve. 15 пунктов эпика «Агентная обвязка 2026-10» в фазу не входят, кроме, может быть, короткого AGENTS.md.
